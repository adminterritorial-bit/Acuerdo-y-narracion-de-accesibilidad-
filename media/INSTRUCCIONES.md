# Archivos de narración y acuerdo

## Narración con voz humana

Sube aquí el archivo **narracion-completa.mp3** (exactamente ese nombre). El sitio lo detecta automáticamente y activa el reproductor, sin editar código. Español hablado (variedad colombiana); grabación aprobada tras cotejar cada artículo y las tablas. No uses el MP3 robótico anterior.

## Copia del documento

Sube aquí el archivo **acuerdo-original.pdf** (exactamente ese nombre). Las referencias de cada una de las 25 páginas abrirán esta copia con su número de página.

Si el archivo excede el límite de GitHub de 100 MB, deberá alojarse por otro mecanismo y editar las rutas de la página.
